# Проект: Платформа школьников Брянской области

## Цель
Создать простую и понятную веб-платформу для школьников региона, где они могут:
- публиковать свои проекты,
- искать команду для участия в конкурсах,
- узнавать о мастер-классах и соревнованиях,
- обсуждать идеи и проекты в комментариях.

## Основные сущности
- Пользователь и профиль школьника
- Проекты с тегами
- Комментарии и голосование
- Объявления о поиске команды
- Афиша мероприятий

## Основной стек
- Python
- Django
- SQLite на старте
- HTML-шаблоны Django
- CSS для простого дизайна

## MVP-модули
1. Главная страница и базовый шаблон
2. Регистрация, вход и профиль
3. Портфолио проектов
4. Доска объявлений
5. Афиша событий

## Порядок разработки
1. Базовый каркас проекта
2. Работа с пользователями и профилями
3. Проекты и комментарии
4. Команда и отклики
5. События
6. Дизайн и безопасность
