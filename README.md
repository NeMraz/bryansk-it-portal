# Брянский школьный IT-портал

## Запуск на Windows

Откройте PowerShell в папке проекта и один раз создайте виртуальное окружение и
установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
```

Для последующих запусков достаточно активировать окружение и запустить сервер:

```powershell
.\.venv\Scripts\Activate.ps1
python manage.py runserver
```

Откройте главную страницу по адресу <http://127.0.0.1:8000/>.

Если PowerShell запретит активацию окружения, можно запускать команды напрямую:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

## Аккаунты

- Регистрация: `/accounts/register/`
- Вход: `/accounts/login/`
- Профиль пользователя: `/accounts/profile/<номер пользователя>/`
- Редактирование своего профиля: `/accounts/profile/edit/`
- Панель администратора: `/admin/`

## Доска объявлений

- Объявления с открытым набором: `/team/`
- Создать объявление: `/team/create/`
- Мои объявления и их отклики: `/team/my/`
- Очередь модерации (для сотрудников): `/team/moderation/`

## Афиша мероприятий

- Предстоящие события: `/events/`
- Прошедшие события: `/events/?past=1`
- Новые события добавляются через `/admin/`.

## Жалобы и безопасность

- Очередь жалоб для сотрудников: `/complaints/`
- Загруженные изображения ограничены размером 5 МБ.
- Страница-заготовка политики обработки данных доступна по адресу `/privacy/`.
- Перед размещением на сервере задайте переменные окружения `DJANGO_SECRET_KEY`,
  `DJANGO_DEBUG=0` и `DJANGO_ALLOWED_HOSTS` со списком доменов через запятую.
- Пример переменных сервера находится в `.env.example`. Это образец, Django
  автоматически его не загружает: задайте значения в панели хостинга или окружении.
- HTTPS-защита включается только при `DJANGO_HTTPS=1` и после настройки HTTPS
  на сервере/доверенном прокси.
- Политика на сайте — незаполненная заготовка, а не юридически готовый документ.
  До использования с реальными пользователями её и порядок согласия для
  несовершеннолетних должна проверить ответственная организация с юристом.
- Не размещайте настоящие данные школьников на демо-хостинге. Для публичного
  запуска заранее согласуйте оператора сайта, место хранения данных и резервное
  копирование.

Перед запуском на сервере соберите статические файлы:

```powershell
python manage.py collectstatic --noinput
```

Каталог `staticfiles/` должен отдаваться сервером веб-хостинга по `/static/`.
Загруженные пользователями файлы из `media/` тоже должен обслуживать хостинг;
при `DEBUG=0` Django не раздаёт их автоматически. Адрес админки локально
`/admin/`; на сервере его можно изменить через `DJANGO_ADMIN_URL`.

Проверки проекта:

```powershell
python manage.py test
python manage.py check --deploy
```

Для подробного списка тестов или запуска одного приложения:

```powershell
python manage.py test -v 2
python manage.py test portfolio
```

Тесты используют отдельную временную базу данных и не изменяют `db.sqlite3`.
